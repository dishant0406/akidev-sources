# Asian drama research evidence

Date: 2026-11-25

This folder holds selected public responses from the Asian drama research. The main report is `../../asian-drama-torrent-coverage-2026-11-25.md`.

The files show catalog metadata, torrent search responses, and candidate source behavior. They contain no account key, password, or private endpoint.

- `crash-landing-meta.json`
